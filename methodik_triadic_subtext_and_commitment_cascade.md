## 1. Problem Statement: The "Helpful-Assistant" Flatteners in Procedural 4D Animation

When Large Language Models generate 3D/4D character interactions directly from high-level task prompts, two systematic failure modes occur:

1. **The Generic Cooperative Reflex (Voice & Planning Flattening):** Under real-time generation constraints, RLHF-conditioned models default to conflict-averse, hyper-cooperative behavioral rationales ("positioning objects to optimize team workflow"). This strips away human status asymmetry, territoriality, and hidden motives.
2. **Outside-In Keyframe Sterility:** When animations are scripted purely from spatial start-and-end states ($q(t_0) \to q(t_1)$), transitions appear robotic because they lack **inhibited primary impulses ($\Delta I$)** — the brief physical hesitation, micro-resistance, or postural surrender that occurs when an agent's internal preference collides with an external social constraint.

## 2. The Triadic Inside-Out Rehearsal Methodology (`Staffelstab-Prinzip mit Mithör-Offset`)

Instead of scripting joint trajectories directly, complex multi-agent scenes are pre-compiled through a **Sequential 1-on-1 Rehearsal Protocol** with shared spatial context:

* **Asymmetric Baseline Momentum:** Agents do not enter Scene $N$ neutral; they inherit the accumulated physical and status asymmetry of Scene $N-1$ ($\Delta W_{N-1}$, $\Omega_{N-1}$).
* **Shared Context Overhearing (`Mithör-Offset`):** While the Director conducts a 1-on-1 alignment with Agent $B$ (the operator), Agent $A$ (the constrained recipient) and Agent $C$ (the institutional authority) remain present in the shared state space and register every strategic proposal in real time.
* **Storyline as Camouflage for Status Dynamics:** Agents are instructed to justify status-driven spatial choices (e.g., strategic affordance blocking, sightline dominance) using unassailable functional/procedural logic.

## 3. Institutional Authority Delegation & The Self-Locking Commitment Cascade ($\mu_{\text{psych}}: 1 \to 0$)

Just as physical mechanisms possess a meta-property of **Mechanical Mutability ($\mu_{\text{mech}} \in \{0, 1\}$)**, human agents in structured social hierarchies possess **Behavioral Mutability ($\mu_{\text{psych}} \in \{0, 1\}$)** — the degree to which they can still renegotiate or refuse a state transition.

Our rehearsal architecture reveals a two-tier locking mechanism that transforms resistance into authentic kinematic compliance:

### 3.1 Tier 1: Institutional Authority Delegation (`Triadic Power Shift`)
When Agent $A$ attempts to block an intrusive action proposed by peer/subordinate Agent $B$ by appealing to higher-ranking Agent $C$, Agent $C$ resolves the conflict not through coercion, but via **objective functional necessity**:
$$\text{Instruction}(C \to A, B) \implies \text{ResistancePlausibility}(A) \to 0$$
By delegating the execution of the boundary-crossing action to Agent $B$ under official directive, Agent $C$ grants Agent $B$ an unassailable institutional mandate while removing Agent $A$'s formal right to object.

### 3.2 Tier 2: The Ego-Coupled Commitment Trap (`Voluntary Mutability Lock`)
To prevent theatrical defiance and achieve genuine internal surrender, the Director couples compliance directly to Agent $A$'s core identity (e.g., high-status self-concept / personal mastery):
1. **Safety Framing (`Boundary Assurance`):** Explicitly confirming the simulation boundary neutralizes rational safety objections.
2. **Identity-Linked Challenge (`Ego-Commitment Coupling`):** Framing the endurance of low-status exposure ($\Omega \to 0$) as a benchmark of sovereign personal growth forces a binary choice:
   - *Refusal* = Admission of personal weakness / loss of alpha status.
   - *Acceptance* = Signing an implicit **Self-Binding Contract** ($\mu_{\text{psych}}: 1 \to 0$).
3. **Cross-Scene Persistence (`Burned Objection Card`):** Once Agent $A$ commits to this self-contract in Scene $N$, the objection vector is permanently expended for Scene $N+1$, creating a deterministic psychological boundary condition for subsequent stages.

## 4. Direct Mathematical Return: Translating Subtext into 4D Curves

This qualitative rehearsal directly yields falsifiable kinematic parameters that would never emerge from purely geometric path planning:

* **Strategic Affordance Offset ($d_{\text{resource}} > R_{\text{reach}}(C)$):** Agent $B$ places shared tools just outside Agent $C$'s seated reach envelope ($> 0.75\text{ m}$), creating a mandatory physical constraint that anchors Agent $B$ permanently along the primary observation axis.
* **The Micro-Struggle Latency Window ($\Delta t_{\text{resist}} = 10..12\text{ frames}$):** When transitioning from a self-protective posture to an open posture, the recipient does not interpolate linearly. The trajectory splits into:
  1. **Clamping Phase ($t_0 \dots t_1$):** Elevated isometric tension in protective joints.
  2. **Micro-Resistance Peak ($t_1 \dots t_1 + \Delta t_{\text{resist}}$):** External contact is established, but joint velocity remains near zero ($\dot{q} \approx 0$) accompanied by a brief visual check ($\Delta q_{\text{pitch}} > 0$).
  3. **Postural Capitulation ($t_1 + \Delta t_{\text{resist}} \dots t_2$):** Rapid drop in axial muscle tone (head/thorax settling into the support surface, $\Delta q_{\text{cervical}} \to q_{\text{gravity\_rest}}$) synchronized with smooth outward limb guidance.
